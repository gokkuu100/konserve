# Konserve - Environmental Conservation App

## Overview
Konserve is an Android application designed to promote environmental conservation and sustainability. The app allows users to view environmental reports, track recycling activities, earn rewards for eco-friendly actions, and engage with a community of environmentally conscious individuals.

## Features

### 1. Environmental Reports
- View latest environmental reports and initiatives
- Expandable card view for detailed information
- Real-time updates using Firebase
- Image support for visual documentation

### 2. Reward System
- Earn points for eco-friendly activities
- Redeem reward codes
- Track loyalty points
- View redemption history

### 3. User Authentication
- Secure login and registration
- Profile management
- Firebase Authentication integration

### 4. Community Engagement
- Report environmental incidents
- Chat functionality ("Talk to Us")
- View and share environmental initiatives

## Technical Stack

### Frontend
- Native Android (Kotlin)
- Material Design components
- RecyclerView with custom adapters
- Glide for image loading
- Custom animations and transitions

### Backend
- Firebase Authentication
- Firebase Firestore
- Real-time data synchronization
- Cloud storage for images


## Setup and Installation

### Prerequisites
- Android Studio Arctic Fox or later
- JDK 11 or later
- Android SDK with minimum API level 21
- Firebase account and project setup

### Firebase Setup
1. Create a new Firebase project
2. Add your Android app to Firebase project
3. Download `google-services.json`
4. Place it in the app directory
5. Configure Firebase Authentication and Firestore

### Build and Run
1. Clone the repository:
```bash
git clone https://github.com/gokkuu100/Konserve.git
```

2. Open project in Android Studio

3. Sync Gradle files

4. Run the app on an emulator or physical device
